CORE VISION

You are building a **personal web application (NOT for public use)** designed to act as:

👉 A **Founder Intelligence System**
👉 A **Decision-Making Accelerator**
👉 A **Time-to-Market Optimization Tool**

This system helps the user:

* Think clearly
* Validate ideas fast
* Execute using Scrum
* Track progress vs time
* Learn from real conversations
* Build business intuition (CAC, LTV, etc.)
* Store and reuse knowledge intelligently

---

## 🧠 PRODUCT PHILOSOPHY

This is NOT:

* A note-taking app
* A task manager
* A file storage tool

This IS:

👉 A **thinking + execution system**

Every feature must answer:

> “Does this reduce friction in thinking or execution?”

---

## ⚡ KEY PRINCIPLES

### 1. Frictionless by default

* Every action < 2 clicks
* Input must be fast (no heavy forms)

### 2. Speed of thought > UI beauty

* UI is clean but secondary to speed

### 3. Evolutive system

* Modular
* Scalable for future AI & analytics

### 4. Reality-driven

* Based on real conversations
* Based on time spent
* Based on decisions made

---

## 🧱 CORE MODULES

---

### 1. 🏠 DASHBOARD (COMMAND CENTER)

Displays:

* Active project
* Current section
* Current sprint
* Time-to-Market (TTM counter)
* Time spent per section
* Delay indicators:

  * “You’ve been on Problem Validation for 3 days”
  * “You may be overthinking”

👉 Must feel like a **control tower**

---

### 2. 📂 PROJECT WORKSPACE

#### Left Sidebar:

* Sections (like slides)

#### Main Area:

Dynamic based on section

---

### 3. 🧠 SECTION ENGINE (MOST IMPORTANT PART)

Each section contains:

### A. Notes Layer

* Fast writing (Markdown or simple editor)
* No friction typing

### B. File Layer

* Upload via Cloudinary
* PDFs, Excel, Word, images
* Attach anywhere

### C. Conversation Layer (CRITICAL)

* Log real conversations:

  * Person
  * Context
  * Pain points
  * Signals
  * Trust level

### D. Insight Layer

* Extract structured insights from conversations

---
